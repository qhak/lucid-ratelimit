# Security Policy

Lucid RateLimit is security-relevant infrastructure. Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting for this repository when it is enabled. If that feature is unavailable, contact the maintainers through a verified repository profile or organization channel; do not include secrets in a public issue.

Include the affected version, deployment assumptions, reproduction steps, and potential impact. The project will coordinate a fix and disclosure with the reporter. Do not send real API keys, customer identifiers, or request payloads.

Rate limiting is one abuse-control layer. It is not a complete bot-defense or DDoS mitigation system.
